# Reading an Isochron

An interactive explainer for Rb–Sr isochrons, written for GEOL 445 Geochemistry at BYU (Week 9, Radioactive clocks).

**To use it:** download `index.html` and open it in any web browser. It is a single self-contained file (photos and code are built in) and works offline.

What is inside:

1. The problem an isochron solves, and why minerals get different amounts of Rb
2. Rewind a real rock: the Baltimore Gneiss whole rocks and minerals, run backward in time
3. The isochron equation, built one step at a time
4. Fit the line yourself, then a worked example
5. Two lines on one plot (whole-rock vs mineral isochrons) and closure temperatures, with a cooling-rate slider
6. When a date is an age
7. The same line for every clock (Sm–Nd, Rb–Sr, Lu–Hf, U–Pb) and a decay race
8. What geologists use today, with a clock-window explorer and "pick the clock" questions
9. Check yourself (click-to-answer questions)
10. Sources and photo credits
